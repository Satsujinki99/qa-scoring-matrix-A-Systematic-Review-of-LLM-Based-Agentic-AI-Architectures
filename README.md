## Overview

This repository provides supplementary materials for the accepted IEEE conference paper:

**Agentic AI for Complex Task Execution: A Systematic Review of LLM-Based Agentic AI Architectures**  
Furqon Aryadana, Kevin Anugerah Faza, RM. Novian Malcolm Bayuputra, Rizka Wakhidatus Sholikah  
Department of Information Technology, Sepuluh Nopember Institute of Technology (ITS), Surabaya, Indonesia  
2026 13th International Conference on Electrical Engineering, Computer Science and Informatics (EECSI 2026)

The repository hosts the supplementary **Quality Assessment (QA) scoring matrix** and **SLR data extraction tables** for the **33 primary studies** analyzed in the review.

## Quality Assessment (QA) Methodology

The QA process follows **Kitchenham's SLR Guidelines** and uses **PICOC** criteria to structure inclusion quality checks.

### Scoring Scheme

- 7 evaluation criteria
- Scale per criterion: **0-2**
- Maximum score: **14**
- Inclusion threshold: **>= 10**

### Evaluation Criteria

1. Clarity of proposed/evaluated architecture
2. Explicitness of study objective
3. Description of core architectural components
4. Use of benchmarks/defined task settings
5. Methodological detail for reproducibility
6. Comparison with baselines/justification
7. Discussion of limitations/failure modes

### QA Statistics

- Total primary studies: **33**
- Score range: **10 to 13**
- Average score: **11.7**
